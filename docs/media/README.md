The banner and icon were created using the built-in image-generation tool. The [full prompts](prompts.md) are saved alongside them. They are branding artwork rather than application screenshots.

The screenshots were captured directly from the running app with browser screenshot tools. Their 18 fantasy icons were procedurally drawn specifically for this public demonstration. Replacement images are the app's built-in test-provider recolors, not examples of an external image model's capabilities. No original game artwork, keys, production catalog, or backups appear in these screenshots. The screenshots have not been composited into a mock interface.
