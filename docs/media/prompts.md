# Branding generation prompts

Created with the built-in image-generation tool. These are branding illustrations, not screenshots or measured examples of model output quality.

## README banner

Use case: ads-marketing. Create a polished wide landscape GitHub README banner for an open-source developer tool called Art Restyler. Intended aspect ratio 2.5:1, ideally 1600x640. Design: dark charcoal studio backdrop with subtle fine grid and understated luminous mint and violet accents. On the right show an exquisite floating 2D game potion bottle, transitioning across a clean diagonal split from simple gray prototype sprite into vibrant hand-painted emerald glass, copper stopper, lavender magical wisps. A few restrained sprite-frame outlines evoke a local art workflow. Keep the left half spacious and typography immaculate. Exact text only: large 'ART RESTYLER', below 'Restyle your Unity art.', small 'by Dawj Games'. Clean contemporary sans serif, white headline, excellent contrast. Elegant developer-tool branding, tactile game art, crisp flat front-facing composition. No fake application screenshot, no Unity or other company logos, no watermark. Keep all lettering safely inset from edges.

## App / profile icon

Use case: logo-brand. Create one square app profile image for Art Restyler, an open-source Unity 2D art restyling developer tool by Dawj Games. Premium, memorable symbol: a single small magical artist paintbrush crossing a faceted emerald sprite tile, with one subtle violet sparkle at the brush tip. Icon should communicate art transformation and game sprites. Dark charcoal solid background, mint emerald and violet accents with warm ivory brush bristles, refined softly shaded 3D illustration with strong graphic silhouette, restrained lighting. Centered composition with generous safe margin, clearly readable as a tiny GitHub avatar, square 1024x1024. No text, no initials, no extra tools, no third-party logos, no watermark, no mockup frame.
