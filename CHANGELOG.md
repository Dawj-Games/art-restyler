# Changelog

## 0.1.0 — 2026-10-26

- Extracted the local Unity 2D art workflow into a standalone open-source tool.
- Added project initialization, generic categorization examples, and platform launch instructions.
- Added portable agent batches that preserve complete per-asset prompts and use the configured port.
- Kept all project-specific configuration, art, catalogs, keys, attempts, and backups out of the repository.
- Added local request origin/host checks and protection against overwriting external edits during rollback.
- Added documentation, synthetic integration tests, and a cross-platform CI workflow.
